# La Velada del Año V - Lloc Web Oficial

Aquest projecte és una aplicació web desenvolupada per a la gestió i difusió de l'esdeveniment "La Velada del Año V".

 # Estructura del projecte
- `index.html`: Pàgina principal amb el comptador enrere.
- `combats.html`: Cartellera detallada dels combats.
- `entrades.html`: Formulari de reserva i calculadora de preus.
- `faq.html`: Preguntes freqüents amb seccions desplegables.
- `css/`: Estils globals de l'aplicació (`styles.css`).
- `js/`: Lògica interactiva JavaScript (`main.js`).
- `img/`: Recursos d'imatges del projecte.

# Tecnologies utilitzades
- HTML5 semàntic
- CSS3 (Flexbox & Grid)
- JavaScript Vanilla (DOM)
